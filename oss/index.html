Open-source source code

Last updated August 5, 2026

Why this page exists: some of the open-source components redistributed in the Brilliante apps are licensed on terms that ask us to make their source code available to you. This page hosts that source, for the exact versions we ship, under each component’s own license.

Every archive below is the unmodified upstream source for the version built into the shipping product — byte for byte, with each project’s own license and copyright files intact inside it. We publish a SHA‑512 for each so you can verify what you downloaded.

The full list of open-source components used in each app, with their licenses, is in the NOTICES file installed alongside the app and in the app’s Open-source licenses dialog. Only components whose license asks for source availability are hosted here.
